🔐 Auth & token security

Google OAuth 2.0 + PKCE (S256). Refresh tokens encrypted at rest AES-256-GCM — server-side only, never sent to any frontend. Cookie sessions; acting user always derived from the verified session.

STORAGE

🗂️ Metadata store (adapter seam)

Default: JSON file store (data/readspace-db.json) — users, workspaces, saved links, transfer logs. Set MONGODB_URI → MongoDB/Atlas with the same MongoDB-shaped documents.

📄 File contents — where they belong

ReadSpace stores references and metadata only. Document bytes stay in the user's Google Drive (or on the local device); every Drive read/upload runs server-side with the user's own authorized token.
